MLB Over/Under Prediction & Backtesting

This repository contains a quantitative pipeline built to model MLB game totals (Over/Under) and backtest expected value against consensus market lines.

The primary goal of this project was to build a complete algorithmic betting architecture—from data ingestion and statistical modeling to Monte Carlo simulation and dynamic bankroll management. While the final model did not achieve a positive ROI in true out-of-sample backtesting against actual 2026 sports book lines, the project served as a rigorous exercise in quantitative finance principles, handling overdispersion in sports data, and building realistic P&L simulators.
